# Public Home Structure Reference

**Reviewed source:** https://animex.one/home on 23 August 2026.

This note documents high-level public layout observations only. It is not a request to reuse source code, artwork, copy, logos, or content from the reference site.

## Useful hierarchy patterns

The page uses a clear viewing-first progression: a single full-width featured title with immediate watch and detail actions; a dense poster-led release rail; then several repeatable discovery rows for seasonal popularity, movies, and upcoming titles. This keeps most navigation decisions within one scroll and gives poster artwork more visual weight than card chrome.

It also keeps supporting modules compact. Metadata sits near titles, while large empty panels and explanatory copy are minimized. The lower page includes community modules, which are intentionally excluded from the requested Aniraku redesign.

## Original Aniraku interpretation

The Aniraku redesign will preserve its own black, off-white, and signal-red editorial language. It will retain real backend-proxied AniList records and current routes, but shift toward a denser poster-grid discovery hierarchy: **single featured trend**, **now airing**, **continue watching when signed in**, **seasonal favorites**, **movie night**, and **genre entry points**. No Animex media, labels, code, or community/post/comment panels will be copied.
